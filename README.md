# Circular Motion Simulator

**This program is made to simulate circular motion at an A-level Physics level in a way that is useful to students who struggle with the topic.**

<img width="2370" height="1524" alt="image" src="https://github.com/user-attachments/assets/18a61b14-be9c-46ff-8b86-f6f9c6db41b5" />

## Features
- Sliders (control values for the simulation)
- Dials display direction and magnitude of values
- Release button allows ball to be released from circular motion and continue as it would in real life
- Information points that explain the purpose behind different features
- Live formulae that update as the sliders change to demonstrate how the formulae link to the simulation

## How to run
1. Download the 'CircularMotion.jar' file from the **Releases** section on this page's right.
2. Double click the file.

## Assumptions
- This project assumes that the ball is always in Uniform Circular Motion (unless the ball is released)
- The project models circular motion in a horizontal plane (meaning gravity is not a component of the centripetal force)
